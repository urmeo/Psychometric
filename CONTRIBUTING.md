# Contributing

- Preserve instrument wording, keys and notices. Use primary sources for scoring changes; add a synthetic regression. English STAI X and French STAI Y differ.
- Run `npm ci`, `npm run check:vendor`, `npm test` and `npm audit --audit-level=high`. Check both interfaces and downloads.
- Branch from `main`; use a specific commit title such as `updated scoring`. Include expected results and checks. Read [instrument rights](NOTICE.md).
